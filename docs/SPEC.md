# Couchpad — спецификация продукта

> Рабочее название. Финальное имя выбрать до публикации (проверить Google Play и товарные знаки).

## 1. Что это
Android-приложение и программа-агент для Windows, которые превращают телефон в пульт от компьютера:
тачпад и клавиатура, файлы, буфер обмена, питание, включение по сети и просмотр экрана через интернет.

**Для кого:** в первую очередь обычный пользователь, который в настройках сетей и BIOS не разбирается. Но и опытному даём настроить всё, что можно, и объясняем, что делает каждая настройка.
**Главный принцип:** всё работает «из коробки» с разумными значениями по умолчанию, каждая функция включается и выключается в настройках, а сложные вещи (Wake-on-LAN, доступ из интернета) проходятся через мастер с проверками и подсказками. Подробнее — раздел 5.

### Конкуренты и чем отличаемся
Проект **с открытым кодом, на пожертвованиях** (раздел 6).

| Продукт | Что умеет | Чего не хватает |
|---|---|---|
| Unified Remote | тачпад, пульты, файлы | устаревший интерфейс, экран только в платной версии |
| KDE Connect | тачпад, файлы, буфер | сложная настройка, на Windows работает слабо |
| Remote Mouse | тачпад, клавиши | ни файлов, ни экрана |
| AnyDesk / Chrome Remote Desktop | экран через интернет | без тачпада-пульта, без WoL, на телефоне неудобно |

**Наше отличие:** всё в одном приложении, современный интерфейс, мастер настройки Wake-on-LAN и доступа из интернета, сопряжение по QR-коду за 10 секунд.

## 2. Архитектура
```
┌──────────────────┐  домашняя сеть: TLS (WebSocket)   ┌──────────────────┐
│  Приложение      │ ◄───────────────────────────────► │  Агент Windows   │
│  Kotlin Multi-   │  интернет: WebRTC (P2P) через      │  C# / .NET 10    │
│  platform +      │  сигнальный сервер, TURN —         │  трей + служба   │
│  Compose MP      │  запасной ретранслятор             └──────────────────┘
│  Android (iOS —  │                                            ▲
│  потом)          │  UDP «магический пакет» (WoL)              │
└──────────────────┘ ─────────────────────► сетевая карта ПК ───┘
```

### Агент Windows (`agent/`)
- **C# / .NET 10 (LTS)**: родной доступ к WinAPI (`SendInput`, DXGI Desktop Duplication, Media Foundation), один подписанный установщик, без Python.
- Две части:
  - **Служба** (от SYSTEM): работает до входа в Windows и на экране блокировки, выполняет питание и WoL-настройки, запускает пользовательскую часть.
  - **Приложение в трее** (в сессии пользователя): ввод мыши и клавиатуры, буфер обмена, захват экрана, окно настроек, QR-код сопряжения.
- Автозапуск, автообновление, логи с ротацией.

### Мобильное приложение (`mobile/`)
- **Kotlin Multiplatform + Compose Multiplatform**: сначала выпускаем Android, но логику (протокол, шифрование, сопряжение, настройки, файлы, WoL) и экраны пишем в общем модуле. Тогда iPhone-версия — это добавить iOS-цель и платформенные куски, а не писать всё заново.
- Модули: `shared` (логика и UI), `androidApp`, позже `iosApp`. Платформенное — через `expect`/`actual`: поиск в сети, доступ к файлам, видео-декодер, фоновая работа, виджеты.
- Material 3 (светлая и тёмная тема, динамические цвета на Android).
- Поиск компьютеров в сети через mDNS (NSD на Android, Bonjour на iOS), без ввода IP.
- На Android foreground-сервис держит соединение, пока открыт пульт или идёт передача файлов.
- Несколько компьютеров в списке.
- Только свободные зависимости (без Google Play Services, Firebase и закрытых SDK), чтобы приложение можно было собрать из исходников и выложить в F-Droid. QR-сканер — ZXing.
- Минимальная версия Android 8.0 (API 26).

### Сервер связи (`relay/`) — для экрана через интернет
- Сигнальный сервер (знакомит телефон и ПК) + TURN (coturn) как запасной ретранслятор, когда прямое соединение не выходит.
- Открытый код и Docker-образ: любой может поднять свой сервер и указать его в настройках. По умолчанию — общий сервер проекта, который оплачивается из пожертвований.
- Содержимое сессии сервер не видит: трафик зашифрован между телефоном и ПК.

### Протокол (`protocol/`)
- Управление: сообщения в бинарном формате (Protobuf) поверх WebSocket + TLS.
- Движения мыши — отдельный лёгкий канал с минимальной задержкой (собираем до 120 событий/с, шлём пачками).
- Файлы — отдельный поток с докачкой.
- Экран — видеопоток H.264 (аппаратное кодирование на ПК, MediaCodec на телефоне), запасной вариант — JPEG.
- Версия протокола в рукопожатии: старое приложение и новый агент договариваются о возможностях.

## 3. Безопасность (обязательная часть, не «потом»)
- **Сопряжение по QR-коду:** агент показывает QR (адрес + одноразовый ключ), телефон сканирует, стороны обмениваются ключами (X25519), дальше соединение только с сопряжёнными устройствами. Запасной вариант — 6-значный код.
- Весь трафик зашифрован (TLS 1.3 с закреплённым сертификатом агента / DTLS в WebRTC).
- В агенте видно список сопряжённых телефонов: отозвать доступ одной кнопкой.
- Права по функциям: для каждого телефона включаются отдельно (ввод, файлы, буфер, питание, экран).
- Опасные действия (выключение, удаление файлов) — с подтверждением на телефоне; по желанию — ещё и подтверждение на ПК для экрана.
- Пока кто-то смотрит экран, на ПК видна рамка или значок, сессию можно прервать.
- Агент слушает только локальную сеть; доступ из интернета — только через наш сервер с аутентификацией, без открытых портов.

## 4. Функции

### 4.1 Тачпад (домашняя сеть)
- Область тачпада, **внизу кнопки ЛКМ и ПКМ** (и опционально СКМ). Кнопку можно зажать: удерживая ЛКМ, второй палец тащит.
- Жесты: тап — клик, двойной тап с удержанием — перетаскивание, два пальца — прокрутка, тап двумя — ПКМ, три пальца влево/вправо — Alt+Tab, щипок — Ctrl+колесо (зум).
- Полоса прокрутки сбоку (вкл/выкл).
- Настройки: чувствительность, ускорение, скорость прокрутки, инверсия прокрутки, вибрация, размер кнопок, левша (кнопки зеркально), держать экран включённым.
- Работает в портретной и альбомной ориентации.

### 4.2 Клавиатура и кнопки
- Ввод текста системной клавиатурой (в том числе голосом), кириллица и эмодзи — через Unicode-ввод, без переключения раскладки на ПК.
- Панель спецклавиш: Esc, Tab, Win, Ctrl, Alt, Shift (залипающие), стрелки, Home/End, PgUp/PgDn, Del, F1–F12.
- Готовые сочетания: копировать, вставить, отменить, Alt+Tab, Alt+F4, Win+D, Win+L, диспетчер задач, скриншот.
- Медиа: громкость, без звука, плей/пауза, следующий/предыдущий трек.
- **Свои кнопки:** пользователь собирает панель из любых сочетаний, команд запуска программ и ссылок.

### 4.3 Питание и мониторы
- Выключить, перезагрузить, сон, гибернация, заблокировать, выйти из учётной записи.
- **Выключить мониторы** — отдельная крупная кнопка на экране «Питание» и быстрая кнопка в шторке пульта (можно вынести и на панель тачпада):
  - гасит все мониторы, компьютер при этом продолжает работать (музыка, загрузки, игры не прерываются);
  - включить обратно: кнопкой «Включить мониторы» в приложении, любым движением на тачпаде или нажатием на ПК — что именно будит, выбирается в настройках («только кнопкой из приложения» удобно, чтобы случайный толчок мыши не будил экран ночью);
  - таймер «выключить мониторы через N минут».
- Виджет на рабочий стол Android и плитка в шторке быстрых настроек: «Выключить мониторы», «Заблокировать», «Включить ПК» — без открытия приложения.
- Таймер: «выключить / перезагрузить / сон через 30 / 60 / 90 мин или в указанное время» с отменой; на ПК перед срабатыванием всплывает уведомление с кнопкой «Отменить».
- Подтверждение перед выключением и перезагрузкой (вкл/выкл в настройках).
- Если на ПК есть несохранённые программы: выбор «завершить мягко» (Windows спросит про сохранение) или «принудительно» — с объяснением разницы.

### 4.4 Файловый менеджер (в обе стороны)
Доступ симметричный: каждая сторона сама решает, что открыть другой.

**ПК → телефон** (с телефона смотрим файлы компьютера)
- В агенте пользователь выбирает, что доступно телефону: **отдельные папки** (по умолчанию: Рабочий стол, Загрузки, Документы, Изображения) или **весь компьютер** (все диски). Для каждой папки — «только чтение» или «чтение и запись».
- На телефоне: просмотр списком и сеткой, превью фото и видео, сортировка, поиск.
- Скачать на телефон, загрузить с телефона на ПК, открыть файл на ПК, переименовать, удалить (в корзину Windows), создать папку.

**Телефон → ПК** (с компьютера смотрим файлы телефона)
- В приложении пользователь выбирает, что доступно компьютеру: **отдельные папки** (по умолчанию: Камера, Загрузки, Документы) или **вся память телефона**. Для каждой — «только чтение» или «чтение и запись».
  - Отдельные папки — через системный выбор папки Android (Storage Access Framework), специальных разрешений не нужно.
  - «Вся память» требует разрешения «Доступ ко всем файлам»; приложение объясняет, зачем оно, и работает без него. Вне Google Play (GitHub, F-Droid) ограничений на это разрешение нет.
- На ПК в окне агента — файловый менеджер телефона: те же действия (скачать, загрузить, удалить, создать папку), плюс перетаскивание файлов мышью в окно и из окна.
- Доступ к телефону с ПК работает, только пока приложение подключено; на телефоне при этом висит уведомление «ПК видит ваши файлы» с кнопкой «Отключить».

**Общее**
- Передача в фоне с прогрессом, докачкой после обрыва и очередью, несколько файлов и папок разом.
- «Поделиться» из любого приложения Android → отправить на ПК (в папку «Загрузки» или выбранную).
- «Отправить на телефон» в контекстном меню Проводника Windows (правый клик по файлу).
- Куда складывать принятые файлы — настраивается на каждой стороне.
- Конфликт имён: спросить / заменить / сохранить под новым именем (по умолчанию — спросить).

### 4.5 Буфер обмена
- Кнопки «взять с ПК» и «отправить на ПК»: текст и картинки.
- Автосинхронизация (выключена по умолчанию): что скопировали на одном устройстве, появляется на другом.
- История последних 20 записей на телефоне.

### 4.6 Wake-on-LAN
**Мастер на ПК** (одна кнопка «Настроить включение по сети»):
1. Проверяет, подключён ли ПК кабелем. Если только Wi-Fi — честно предупреждает, что, скорее всего, не сработает.
2. Сам включает в сетевой карте «Пробуждение по магическому пакету» (нужны права администратора, их просит служба).
3. Отключает «Быстрый запуск» Windows (из-за него WoL после выключения часто не работает).
4. Не может проверить BIOS: показывает инструкцию с картинками для популярных плат (ASUS, MSI, Gigabyte, ASRock) и ноутбуков.
5. Тест: «выключите ПК и нажмите на телефоне "Включить"». Результат запоминается.

**На телефоне:** MAC-адрес и адрес сети приходят сами при сопряжении, ручной ввод не нужен. Кнопка «Включить» на карточке компьютера.

**Из интернета** выключенный ПК разбудить может только устройство, которое осталось дома включённым:
- **другой агент** (второй ПК, ноутбук) — будит соседа по нашей команде;
- **роутер** с функцией WoL (Keenetic, ASUS, MikroTik) — инструкции для популярных моделей;
- **старый Android-телефон дома** в режиме «домашний ретранслятор» — наше же приложение.
Мастер подсказывает, какой вариант доступен.

### 4.7 Просмотр экрана и управление (интернет)
- Включается в настройках агента **отдельным переключателем**, выключен по умолчанию.
- В домашней сети работает напрямую; через интернет — WebRTC: прямое P2P-соединение через наш сигнальный сервер, если напрямую не вышло — через TURN-ретранслятор.
- Качество: авто / экономия трафика / максимум; ограничение FPS; выбор монитора; масштаб щипком.
- Режимы управления: «тачпад» (курсор двигается как на ноутбуке) и «прямое касание» (тап = клик в это место).
- Клавиатура и панель спецклавиш поверх экрана.
- Продвинутый режим (для тех, кто разбирается): подключение по адресу Tailscale / своему VPN без нашего сервера.

## 5. Просто для новичка, гибко для опытного
### Новичок: работает само
- **Первый запуск на ПК:** установщик → окно с QR-кодом «Отсканируйте телефоном». Всё.
- **Первый запуск на телефоне:** 3 экрана онбординга → «Найдено: DESKTOP-ABC, подключить?» или сканер QR.
- Значения по умолчанию подобраны так, что настраивать ничего не нужно.
- Каждая функция — карточка с переключателем и короткой подписью «что это и зачем».
- Сложное — только через мастера (Wake-on-LAN, доступ из интернета, доступ к файлам): шаг за шагом, с автоматическими проверками и кнопкой «Проверить ещё раз».
- Ошибки человеческим языком с кнопкой «Как исправить» (не «ECONNREFUSED», а «Компьютер не отвечает. Проверьте, что он включён и в той же Wi-Fi-сети»).

### Опытный: настраивается всё
- Настройки в два слоя: **основные** (видны сразу) и **расширенные** (раздел «Для опытных» в каждом экране настроек).
- У **каждой** настройки: короткая подпись под названием и кнопка «ⓘ Подробнее» — что именно меняется, на что влияет, когда стоит трогать, какое значение по умолчанию. Например, «Порт агента», «Кодек видео», «Битрейт», «Ускорение курсора», «Способ пробуждения мониторов».
- Кнопка «Сбросить к значениям по умолчанию» в каждом разделе.
- Примеры расширенных настроек: порт и сетевой интерфейс агента, ручное добавление ПК по IP, адрес своего сигнального/TURN-сервера, режим «только Tailscale/VPN», кодек и битрейт видео, кривая ускорения курсора, частота отправки движений, размер буфера передачи файлов, журнал отладки и его экспорт.
- Экспорт и импорт настроек (перенести на новый телефон).
- Раздел «Диагностика»: пинг до ПК, скорость сети, версия протокола, журнал подключения — понятным языком, с кнопкой «Отправить отчёт».

### Общее
- Языки: русский и английский с первого релиза.
- Доступность: крупный шрифт, контраст, озвучка TalkBack для всех кнопок.

## 6. Открытый код и распространение
- **Код открыт целиком:** агент, приложение и сервер связи. Лицензия — **GPL-3.0** (агент и приложение) и **AGPL-3.0** (сервер связи): форки обязаны оставаться открытыми, никто не закроет код и не продаст его как своё.
- **Без рекламы, без слежки, без обязательного аккаунта.** Аналитики нет; отчёты о сбоях — только если пользователь сам нажал «Отправить».
- **Где брать:**
  - Android: GitHub Releases (подписанный `.apk`), **F-Droid**, позже Obtainium/IzzyOnDroid. Google Play — не планируем (если передумаем, код к этому готов).
  - Windows: установщик в GitHub Releases, **winget** (`winget install Couchpad`), позже Microsoft Store.
- **Подпись Windows-установщика:** бесплатная подпись для open-source проектов через SignPath Foundation, чтобы SmartScreen не пугал «неизвестным издателем».
- **Пожертвования:** GitHub Sponsors, Boosty, Open Collective (прозрачные расходы на сервер), крипта. Кнопка «Поддержать проект» в приложении и агенте — ненавязчиво, в разделе «О программе», без всплывающих окон.
- **Для разработчиков:** CONTRIBUTING.md, описание протокола в `protocol/`, сборка одной командой, CI на GitHub Actions (сборка и тесты на каждый PR), переводы через Weblate.

## 7. iPhone (потом)
Как это будет устроено и что там иначе, чем на Android:
- Общий код из `mobile/shared` переиспользуется, добавляется `iosApp` (SwiftUI-обёртка вокруг Compose Multiplatform).
- **Нужен Mac** для сборки и аккаунт Apple Developer (99 $/год) для установки на чужие телефоны. Без App Store поставить приложение обычному пользователю почти нельзя (в ЕС есть альтернативные магазины, в остальных странах — только App Store или TestFlight).
- Ограничения iOS:
  - приложение не работает в фоне долго: соединение держится, пока пульт открыт; передача файлов в фоне — через системные фоновые загрузки;
  - для поиска ПК в сети и отправки WoL-пакета нужно разрешение «Локальная сеть» (система спросит пользователя), а для широковещательного WoL-пакета — специальное право от Apple (multicast entitlement), его запрашивают заявкой; запасной вариант — будить через агент на другом ПК или роутер;
  - доступ к файлам — только через приложение «Файлы» и выбранные пользователем папки, «вся память» на iOS невозможна;
  - виджеты и Пункт управления — через WidgetKit и Control Center.
- Видео: декодирование H.264 через VideoToolbox.

## 8. Этапы

| **M0. Каркас** | Агент в трее, приложение-оболочка, поиск в сети, сопряжение по QR, шифрованное соединение | Телефон находит ПК и подключается |
| **M1. Пульт** | Тачпад с кнопками, жесты, клавиатура, спецклавиши, медиа, питание, выключение мониторов, виджет и плитки в шторке | Можно управлять ПК с дивана |
| **M2. Данные** | Файловый менеджер в обе стороны, буфер обмена, «Поделиться → на ПК», «Отправить на телефон» в Проводнике | Перекинуть фото и текст в обе стороны, посмотреть файлы телефона с ПК |
| **M3. Wake-on-LAN** | Мастер на ПК, кнопка «Включить», тест | ПК включается с телефона дома |
| **M4. Экран дома** | Видеопоток H.264, управление, выбор монитора | Плавная картинка по Wi-Fi |
| **M5. Экран через интернет** | Сервер связи (сигналинг + TURN, Docker), WebRTC, привязка ПК к телефону без аккаунта | Работает с мобильного интернета |
| **M6. Релиз** | Подписанный установщик, автообновление, GitHub Releases, F-Droid, winget, сайт, страница пожертвований | Публикация |
| **M7. iPhone** | iOS-цель в общем модуле, App Store / TestFlight | Пульт и файлы на iPhone |

## 9. Что понадобится
- **Для разработки:** Android Studio (с JDK и Android SDK), .NET 10 SDK, git.
- **Для этапа M5:** небольшой VPS для сервера связи (≈5–10 $/мес на старте, из пожертвований).
- **Для релиза:** репозиторий на GitHub, заявка в SignPath Foundation (подпись Windows), заявка в F-Droid, сайт-визитка (GitHub Pages).
- **Для iPhone:** Mac (или облачный Mac в CI) и Apple Developer (99 $/год).
