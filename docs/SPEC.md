# RemoteDesk — спецификация продукта

> Рабочее название. Финальное имя выбрать до публикации (проверить Google Play и товарные знаки).

## 1. Что это
Android-приложение и программа-агент для Windows, которые превращают телефон в пульт от компьютера:
тачпад и клавиатура, файлы, буфер обмена, питание, включение по сети и просмотр экрана через интернет.

**Для кого:** обычный пользователь, который в настройках сетей и BIOS не разбирается.
**Главный принцип:** всё работает «из коробки», каждая функция включается и выключается в настройках, а сложные вещи (Wake-on-LAN, доступ из интернета) проходятся через мастер с проверками и подсказками.

### Конкуренты и чем отличаемся
| Продукт | Что умеет | Чего не хватает |
|---|---|---|
| Unified Remote | тачпад, пульты, файлы | устаревший интерфейс, экран только в платной версии |
| KDE Connect | тачпад, файлы, буфер | сложная настройка, на Windows работает слабо |
| Remote Mouse | тачпад, клавиши | ни файлов, ни экрана |
| AnyDesk / Chrome Remote Desktop | экран через интернет | без тачпада-пульта, без WoL, на телефоне неудобно |

**Наше отличие:** всё в одном приложении, современный интерфейс, мастер настройки Wake-on-LAN и доступа из интернета, сопряжение по QR-коду за 10 секунд.

## 2. Архитектура
```
┌──────────────┐   домашняя сеть: TLS (WebSocket)    ┌──────────────────┐
│  Android     │ ◄─────────────────────────────────► │  Агент Windows   │
│  Kotlin +    │   интернет: WebRTC (P2P) через       │  C# / .NET 8     │
│  Compose     │   наш сигнальный сервер, TURN —      │  трей + служба   │
└──────────────┘   запасной ретранслятор             └──────────────────┘
        │  UDP «магический пакет» (WoL)                       │
        └────────────────────────────────► сетевая карта ПК ──┘
```

### Агент Windows (`agent/`)
- **C# / .NET 8**: родной доступ к WinAPI (`SendInput`, DXGI Desktop Duplication, Media Foundation), один подписанный установщик, без Python.
- Две части:
  - **Служба** (от SYSTEM): работает до входа в Windows и на экране блокировки, выполняет питание и WoL-настройки, запускает пользовательскую часть.
  - **Приложение в трее** (в сессии пользователя): ввод мыши и клавиатуры, буфер обмена, захват экрана, окно настроек, QR-код сопряжения.
- Автозапуск, автообновление, логи с ротацией.

### Android-приложение (`android/`)
- Kotlin, Jetpack Compose, Material 3 (светлая и тёмная тема, динамические цвета).
- Поиск компьютеров в сети через mDNS/NSD, без ввода IP.
- Foreground-сервис держит соединение, пока открыт пульт или идёт передача файлов.
- Настройки в DataStore, несколько компьютеров в списке.
- Минимальная версия Android 8.0 (API 26).

### Протокол (`protocol/`)
- Управление: сообщения в бинарном формате (Protobuf) поверх WebSocket + TLS.
- Движения мыши — отдельный лёгкий канал с минимальной задержкой (собираем до 120 событий/с, шлём пачками).
- Файлы — отдельный поток с докачкой.
- Экран — видеопоток H.264 (аппаратное кодирование на ПК, MediaCodec на телефоне), запасной вариант — JPEG.
- Версия протокола в рукопожатии: старое приложение и новый агент договариваются о возможностях.

## 3. Безопасность (обязательная часть, не «потом»)
- **Сопряжение по QR-коду:** агент показывает QR (адрес + одноразовый ключ), телефон сканирует, стороны обмениваются ключами (X25519), дальше соединение только с сопряжёнными устройствами. Запасной вариант — 6-значный код.
- Весь трафик зашифрован (TLS 1.3 с закреплённым сертификатом агента / DTLS в WebRTC).
- В агенте видно список сопряжённых телефонов: отозвать доступ одной кнопкой.
- Права по функциям: для каждого телефона включаются отдельно (ввод, файлы, буфер, питание, экран).
- Опасные действия (выключение, удаление файлов) — с подтверждением на телефоне; по желанию — ещё и подтверждение на ПК для экрана.
- Пока кто-то смотрит экран, на ПК видна рамка или значок, сессию можно прервать.
- Агент слушает только локальную сеть; доступ из интернета — только через наш сервер с аутентификацией, без открытых портов.

## 4. Функции

### 4.1 Тачпад (домашняя сеть)
- Область тачпада, **внизу кнопки ЛКМ и ПКМ** (и опционально СКМ). Кнопку можно зажать: удерживая ЛКМ, второй палец тащит.
- Жесты: тап — клик, двойной тап с удержанием — перетаскивание, два пальца — прокрутка, тап двумя — ПКМ, три пальца влево/вправо — Alt+Tab, щипок — Ctrl+колесо (зум).
- Полоса прокрутки сбоку (вкл/выкл).
- Настройки: чувствительность, ускорение, скорость прокрутки, инверсия прокрутки, вибрация, размер кнопок, левша (кнопки зеркально), держать экран включённым.
- Работает в портретной и альбомной ориентации.

### 4.2 Клавиатура и кнопки
- Ввод текста системной клавиатурой (в том числе голосом), кириллица и эмодзи — через Unicode-ввод, без переключения раскладки на ПК.
- Панель спецклавиш: Esc, Tab, Win, Ctrl, Alt, Shift (залипающие), стрелки, Home/End, PgUp/PgDn, Del, F1–F12.
- Готовые сочетания: копировать, вставить, отменить, Alt+Tab, Alt+F4, Win+D, Win+L, диспетчер задач, скриншот.
- Медиа: громкость, без звука, плей/пауза, следующий/предыдущий трек.
- **Свои кнопки:** пользователь собирает панель из любых сочетаний, команд запуска программ и ссылок.

### 4.3 Питание и экран
- Выключить, перезагрузить, сон, гибернация, заблокировать, выйти из учётной записи.
- **Выключить мониторы** (до движения мыши / по кнопке «включить»).
- Таймер: «выключить через 30 / 60 / 90 мин» с отменой.
- Подтверждение перед выключением и перезагрузкой (вкл/выкл в настройках).

### 4.4 Файловый менеджер
- В агенте пользователь выбирает, что доступно: **отдельные папки** (по умолчанию: Рабочий стол, Загрузки, Документы) или **весь компьютер**. Режим «только чтение» для каждой папки.
- На телефоне: просмотр списком и сеткой, превью фото, сортировка, поиск.
- Скачать на телефон, загрузить с телефона на ПК, открыть файл на ПК, переименовать, удалить (в корзину), создать папку.
- Передача в фоне с прогрессом и докачкой, несколько файлов разом.
- «Поделиться» из любого приложения Android → отправить на ПК.

### 4.5 Буфер обмена
- Кнопки «взять с ПК» и «отправить на ПК»: текст и картинки.
- Автосинхронизация (выключена по умолчанию): что скопировали на одном устройстве, появляется на другом.
- История последних 20 записей на телефоне.

### 4.6 Wake-on-LAN
**Мастер на ПК** (одна кнопка «Настроить включение по сети»):
1. Проверяет, подключён ли ПК кабелем. Если только Wi-Fi — честно предупреждает, что, скорее всего, не сработает.
2. Сам включает в сетевой карте «Пробуждение по магическому пакету» (нужны права администратора, их просит служба).
3. Отключает «Быстрый запуск» Windows (из-за него WoL после выключения часто не работает).
4. Не может проверить BIOS: показывает инструкцию с картинками для популярных плат (ASUS, MSI, Gigabyte, ASRock) и ноутбуков.
5. Тест: «выключите ПК и нажмите на телефоне "Включить"». Результат запоминается.

**На телефоне:** MAC-адрес и адрес сети приходят сами при сопряжении, ручной ввод не нужен. Кнопка «Включить» на карточке компьютера.

**Из интернета** выключенный ПК разбудить может только устройство, которое осталось дома включённым:
- **другой агент** (второй ПК, ноутбук) — будит соседа по нашей команде;
- **роутер** с функцией WoL (Keenetic, ASUS, MikroTik) — инструкции для популярных моделей;
- **старый Android-телефон дома** в режиме «домашний ретранслятор» — наше же приложение.
Мастер подсказывает, какой вариант доступен.

### 4.7 Просмотр экрана и управление (интернет)
- Включается в настройках агента **отдельным переключателем**, выключен по умолчанию.
- В домашней сети работает напрямую; через интернет — WebRTC: прямое P2P-соединение через наш сигнальный сервер, если напрямую не вышло — через TURN-ретранслятор.
- Качество: авто / экономия трафика / максимум; ограничение FPS; выбор монитора; масштаб щипком.
- Режимы управления: «тачпад» (курсор двигается как на ноутбуке) и «прямое касание» (тап = клик в это место).
- Клавиатура и панель спецклавиш поверх экрана.
- Продвинутый режим (для тех, кто разбирается): подключение по адресу Tailscale / своему VPN без нашего сервера.

## 5. Простота для пользователя
- **Первый запуск на ПК:** установщик → окно с QR-кодом «Отсканируйте телефоном». Всё.
- **Первый запуск на телефоне:** 3 экрана онбординга → «Найдено: DESKTOP-ABC, подключить?» или сканер QR.
- Каждая функция — карточка с переключателем и короткой подписью «что это и зачем».
- Ошибки человеческим языком с кнопкой «Как исправить» (не «ECONNREFUSED», а «Компьютер не отвечает. Проверьте, что он включён и в той же Wi-Fi-сети»).
- Языки: русский и английский с первого релиза.

## 6. Этапы
| Этап | Что получаем | Что проверяем |
|---|---|---|
| **M0. Каркас** | Агент в трее, приложение-оболочка, поиск в сети, сопряжение по QR, шифрованное соединение | Телефон находит ПК и подключается |
| **M1. Пульт** | Тачпад с кнопками, жесты, клавиатура, спецклавиши, медиа, питание, выключение мониторов | Можно управлять ПК с дивана |
| **M2. Данные** | Файловый менеджер, буфер обмена, «Поделиться → на ПК» | Перекинуть фото и текст в обе стороны |
| **M3. Wake-on-LAN** | Мастер на ПК, кнопка «Включить», тест | ПК включается с телефона дома |
| **M4. Экран дома** | Видеопоток H.264, управление, выбор монитора | Плавная картинка по Wi-Fi |
| **M5. Экран через интернет** | Сигнальный сервер, WebRTC, TURN, аккаунты/привязка | Работает с мобильного интернета |
| **M6. Релиз** | Подписанный установщик, автообновление, отчёты о сбоях, политика конфиденциальности, Google Play | Публикация |

## 7. Что понадобится
- **Для разработки:** Android Studio (с JDK и Android SDK), .NET 8 SDK, git.
- **Для этапа M5:** небольшой VPS для сигнального сервера и TURN (≈5–10 $/мес на старте).
- **Для релиза:** аккаунт разработчика Google Play (25 $ разово), сертификат подписи кода для Windows (без него SmartScreen пугает «неизвестный издатель»), политика конфиденциальности, сайт-визитка со ссылкой на агент.

## 8. Открытые вопросы
- Название и иконка.

- Нужны ли macOS и Linux-агенты (потом) и iPhone-приложение (потом).
